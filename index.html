0. 始める前

テンプレの各ファイルは、処理の名前を書いた斜線のコメントと、ここまでと書いた斜線のコメントの間が空いている。ここに自分で書く。読み込みと書き出しは書いてある。

1. 雑音を作る、のせる

1_rand.c 一様乱数のヒストグラム

r = rand() / (RAND_MAX + 1.0);   /* 0以上1未満 */
g[(int)(r * 100)]++;

RAND_MAX で割ると r がちょうど1になることがあり、g[100] は配列の外になる。だから RAND_MAX + 1.0 で割る。どの区間もほぼ100個になればよい。

2_rand_gauss.c ガウス乱数のヒストグラム

/* やり方1 一様乱数12個の和から6を引く */
G = 0; for (k = 0; k < 12; k++) G += rand() / (double)RAND_MAX;
G -= 6;
/* やり方2 Box-Muller。log(0)を避けるため R1 は0にしない */
R1 = (rand() + 1.0) / (RAND_MAX + 1.0);
R2 = rand() / (double)RAND_MAX;
G = sqrt(-2 * log(R1)) * cos(2 * M_PI * R2);

v = (int)(100 + 25 * G);
if (0 <= v && v < 200) g[v]++;

どちらか1つでよい。平均と標準偏差を変えて形の変化を見る、のがテキストの課題。コンパイルで log や sqrt が見つからないと言われたら gcc 2_rand_gauss.c -lm。

3_rand_huka.c 一様雑音をのせる

4_rand_huka_gauss.c ガウス雑音をのせる

5_rand_huka_wb.c ごま塩雑音をのせる

3〜5で共通の注意

  • 最初に g に f を丸ごと写す。テンプレの g は空のまま。写さないと、雑音が当たらなかった画素が真っ黒になる
  • のせる回数は 128×128×割合。40%なら6553回、10%なら1638回
  • 画素の場所は i、j をそれぞれ0〜127の乱数で選ぶ。(int)(rand() / (RAND_MAX + 1.0) * 128)
  • 一様雑音の量は 2 * a * b。a = rand()/RAND_MAX − 0.5、b が最大値
  • 足した値は int の temp で受け、0未満は0、255より上は255にしてから g に入れる
  • ヒストグラムは、全部のせ終わった g を m[g[i][j]]++ で数える
  • 出力の名前は毎回同じで上書きされる。もう1種類を作るときは、走らせたらすぐ名前を変えて取っておく。2章以降のフィルタは rand_huka.raw などを読むので、最後は40%の版に戻しておく

考察のネタ：同じ画素が2回選ばれることがあるので、6553回のせても雑音が当たる画素は40%より少なく、だいたい33%になる。

2. 雑音を消す

6-1_l_filter.c 平均フィルタ 3×3 重みなし

for (i = 1; i < SIZE - 1; i++)
  for (j = 1; j < SIZE - 1; j++) {
    合計 = 0;
    for (k = -1; k <= 1; k++)
      for (l = -1; l <= 1; l++)
        合計 += f[i + k][j + l];
    g[i][j] = 合計 / 9;
  }

7-1_m_filter.c メディアンフィルタ 3×3

並べ替えはバブルソートで足りる。A2のための宿題の h_sort.c がそれ。端の1列は計算しないので0のまま黒い枠になる。5×5なら2列。考察で触れられる。

3. 輪郭を取り出す

/* 基本の微分。4方向の差を取り、絶対値の一番大きいものを使う */
a = f[i+1][j] - f[i-1][j];       /* 縦方向 */
b = f[i][j+1] - f[i][j-1];       /* 横方向 */
c = f[i+1][j+1] - f[i-1][j-1];   /* 斜め */
d = f[i+1][j-1] - f[i-1][j+1];   /* 斜め */
g[i][j] = max(max(a, b), max(c, d));

テンプレの max は絶対値で比べて絶対値を返す。Prewitt は同じ形で、隣の3画素ずつを使い1/3を掛ける。重みはテキスト5ページの4つの表のとおり。

4. 輪郭を強める

/* ラプラシアン */
l[i][j] = f[i-1][j] + f[i+1][j] + f[i][j-1] + f[i][j+1] - 4 * f[i][j];
g[i][j] = f[i][j] - α * l[i][j];
/* アンシャープマスク。l は3×3平均でぼかした画像 */
g[i][j] = f[i][j] + β * (f[i][j] - l[i][j]);
  • g は0〜255に収めてから g1 に写す。テンプレは g1[i][j] = g[i][j] とそのまま写すだけなので、範囲の外の値があると白黒の点が出る
  • α を変えるたびに出力名が同じで上書きされる。走らせたらすぐ名前を変える
  • 雑音画像に使うのは余力がある人だけ

5. レポート用に持ち帰るもの

raw は ImageJ の Import Raw で 8-bit、128×128 にして開く。グラフの作り方はA1と同じで、256階調は横軸の間隔50、縦軸 頻度、横軸 濃度値、Excelブックで保存。

6. レポートに最低限書くこと

実験A2レポートのスライドより。どれも、なぜそうなるかを手法の違いに注目して書く。

  • 雑音をのせた画像の見た目の比較
  • 雑音をのせた画像のヒストグラムの比較
  • 線形フィルタの比較。重みあり、重みなし、5×5
  • 非線形フィルタの比較。3×3と5×5
  • 線形フィルタと非線形フィルタの比較
  • 基本の微分と Prewitt の比較
  • ラプラシアンとアンシャープマスクのパラメータの比較
  • ラプラシアンとアンシャープマスクで輪郭が強まる仕組みの説明と比較
載せる画像の一覧。スライドの3、4ページ
項目中身
原画像比較のための原画像、原画像のヒストグラム
一様雑音一様乱数のヒストグラム。付加画像とそのヒストグラム。40%、平均0、最大値30と、もう1種類宿題
ガウス雑音ガウス乱数のヒストグラム、平均100、標準偏差25。付加画像とそのヒストグラム。40%、平均0、標準偏差30と、もう1種類宿題
ごま塩雑音付加画像とそのヒストグラム。10%と、もう1種類宿題
線形フィルタ雑音3種に3×3重みなし。3×3重みありと5×5重みなし宿題
非線形フィルタ雑音3種に3×3メディアン。5×5宿題
輪郭抽出原画像と雑音3種に、基本の微分と Prewitt
輪郭強調原画像にラプラシアン、α 0.5、1.0、1.5。アンシャープマスク宿題。雑音画像は余力のある人だけ

各画像のパラメータは必ずレポートに書く。フィルタは最低でも上の40%などの雑音画像に対してかける。
